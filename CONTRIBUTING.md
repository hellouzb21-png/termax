# Contributing to termax

Thank you for your interest in contributing to **termax**!

## Development Setup

```bash
git clone https://github.com/hellouzb21-png/termax.git
cd termax
npm install
npm run build
```

## Pull Request Guidelines

1. Fork the repository and create a feature branch (`git checkout -b feat/my-feature`).
2. Ensure TypeScript compiles cleanly with `npm run build`.
3. Follow Conventional Commits (`feat:`, `fix:`, `docs:`, `refactor:`).
4. Open a Pull Request describing the motivation and verification steps.
